# KNOT

Connecting Every Campus. KNOT is a multi-tenant SaaS platform that connects colleges, students, organizers, and administrators into one unified event ecosystem.

## Architecture
- **Backend:** Node.js, Express, TypeScript, PostgreSQL, Prisma ORM
- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS v4, React Router, Recharts
